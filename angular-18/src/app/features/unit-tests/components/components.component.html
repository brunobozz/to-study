Teoria: Testando Componentes (Lógica & DOM)

Testar componentes envolve validar se a lógica em TypeScript é corretamente refletida no layout HTML e se as interações do usuário (como cliques ou digitações) disparam as ações corretas.

Termos chave no teste de componentes:

  • ComponentFixture: O invólucro (wrapper) criado pelo TestBed. Dá acesso tanto à instância TypeScript do componente (fixture.componentInstance) quanto ao elemento renderizado no DOM (fixture.nativeElement).
  • fixture.detectChanges(): Força a rodada de detecção de mudanças do Angular. Essencial após inicializar propriedades ou interagir com o DOM para ver as alterações refletidas no template.
  • By.css(): Utilitário para consultar elementos no DOM de forma robusta e segura independente da plataforma de renderização.
