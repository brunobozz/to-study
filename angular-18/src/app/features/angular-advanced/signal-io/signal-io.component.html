Teoria: Signal Inputs, Outputs & Model

O Angular 17.2+ e 18 introduzem APIs baseadas em Signals para transferência de dados entre componentes, substituindo os decoradores tradicionais para obter consistência de reatividade fina.

  • input() / input.required(): Substitui o decorador @Input(). Os valores recebidos são representados como sinais de leitura. Como são sinais, você pode usá-los em cálculos de computed() e monitorar em effect() nativamente sem precisar de ngOnChanges.
  • output(): Substitui o decorador @Output() e o EventEmitter. Fornece uma API mais simples e leve, mantendo compatibilidade com eventos normais.
  • model(): Cria um canal de comunicação de duas vias (two-way binding) reativo. Se o componente filho modificar o valor do sinal, o componente pai é atualizado automaticamente, e vice-versa.
