Teoria: Arquitetura NgRx (Redux no Angular)

O NgRx Store é um framework de gerenciamento de estado global e reativo baseado em RxJS que segue o padrão Redux. Ele é projetado para grandes aplicações mantendo o fluxo de dados unidirecional e previsível.

Fluxo Unidirecional de Dados:
  1. Componente: Dispara (dispatches) uma Action expressando uma intenção do usuário ou evento do ciclo de vida.
  2. Effects: Interceptam a Action caso ela exija uma ação assíncrona (como uma chamada HTTP). Quando finalizado o processo, o Effect dispara outra Action (ex: Success ou Failure).
  3. Reducers: Funções puras síncronas que capturam a Action e aplicam as mutações imutáveis no estado, retornando um novo estado.
  4. Store: Atualiza o estado centralizado e notifica os subscritores.
  5. Selectors: Componentes leem dados do Store usando Selectors memorizados, garantindo que o componente re-renderize apenas se a sua fatia de dados mudar.
