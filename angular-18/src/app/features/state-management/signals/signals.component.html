Teoria: Reatividade com Angular Signals

Signals são primitivos reativos síncronos que mantêm um valor e notificam os consumidores interessados quando esse valor muda. Eles introduzem uma nova forma de reatividade fina (fine-grained), eliminando a necessidade de verificar toda a árvore de componentes em busca de mudanças (melhorando o desempenho de renderização).

Principais funções do ecossistema de Signals:

  • signal(valorInicial): Cria um sinal gravável (Writable Signal). Podemos atualizar seu valor usando o método .set(novoValor) ou mutar com base no valor anterior usando .update(val => novoVal).
  • computed(() => expressao): Cria um sinal somente-leitura dependente de outros sinais. O cálculo é feito sob demanda (lazy) e seu valor é memorizado (cached). Ele se recalcula somente quando um sinal interno de dependência mudar.
  • effect(() => execucao): Executa uma rotina secundária sempre que os sinais lidos dentro dele mudarem. Ideal para logs, chamadas externas ou persistência (ex: localStorage). Deve ser declarado no construtor.
