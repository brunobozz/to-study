Teoria: Roteamento Preguiçoso (Lazy Routing)

O Lazy Loading atrasa o carregamento de recursos não utilizados até que a rota correspondente seja acessada pelo usuário. Isso reduz drasticamente o tamanho do bundle inicial transmitido ao navegador (melhorando métricas cruciais como LCP - Largest Contentful Paint).

No Angular moderno com a API Standalone, não há necessidade de criar arquivos do tipo NgModule secundários. Nós simplesmente carregamos componentes específicos ou arquivos de sub-rotas de forma preguiçosa usando a sintaxe de importação dinâmica do JavaScript:

  • loadComponent: Carrega dinamicamente apenas o arquivo do componente solicitado.
  • loadChildren: Carrega dinamicamente arquivos de configurações de rotas filhas inteiras (nested routing).
