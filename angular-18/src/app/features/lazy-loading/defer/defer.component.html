Teoria: Deferrable Views (@defer)

As Deferrable Views representam uma das inovações mais importantes do Angular moderno. Elas permitem adiar o carregamento de componentes pesados, pipes ou diretivas diretamente no template usando a sintaxe nativa declarativa @defer.

Blocos estruturais de uma visualização adiável:

  • @defer: O bloco de conteúdo principal que sofrerá o carregamento tardio.
  • @placeholder: Bloco de conteúdo inicial visível antes do carregamento começar.
  • @loading: Conteúdo temporário exibido durante o download do chunk de JavaScript correspondente.
  • @error: Mensagem fallback exibida caso o download do pacote JS falhe.

Você pode disparar o carregamento usando gatilhos (triggers): on idle (padrão, quando a página termina de carregar), on viewport (quando o conteúdo entra na tela), on interaction (no clique ou foco), on hover (quando o mouse passa por cima), on timer(2s) (após um atraso) e when condicao (com base em um sinal/variável boolean).

Prática: Testando Gatilhos de Defer

1. Defer no Clique (on interaction)
@defer (on interaction) { } @placeholder {
Clique aqui para baixar e renderizar
} @loading {
Baixando bundle JS...
}
2. Defer no Mouseover (on hover)
@defer (on hover) { } @placeholder {
Passe o mouse aqui para carregar
}
