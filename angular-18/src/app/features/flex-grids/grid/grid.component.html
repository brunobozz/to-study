CSS Grid (2D Layout)

O CSS Grid cria estruturas bidimensionais, organizando o alinhamento de linhas e colunas paralelamente. Essencial para layouts gerais de páginas complexas.

A propriedade grid-template-columns define as colunas e a largura de cada uma. A propriedade gap especifica o espaçamento entre células.
