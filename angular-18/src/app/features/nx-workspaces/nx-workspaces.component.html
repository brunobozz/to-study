Nx Workspaces (Monorepos)

Teoria: Arquitetura de Monorepos com Nx

O Nx é um sistema de build inteligente e extensível com suporte nativo a monorepos (colocação de múltiplos projetos de software no mesmo repositório Git). Na TownSq, o Nx auxilia a gerenciar grandes bases de código divididas de forma inteligente.

Estrutura organizacional recomendada pelo Nx:

  • Apps (Aplicações): Ficam sob apps/. São cascas de implantação finas (ex: web-portal, mobile-app) que apenas configuram rotas, interceptores globais e importam funcionalidades de bibliotecas. Não devem conter regras de negócio complexas.
  • Libs (Bibliotecas): Ficam sob libs/. São módulos de código isolados e reutilizáveis (ex: componentes de UI compartilhados, lógica de autenticação core, serviços de API).
Nx Computation Caching

O Nx mapeia as dependências entre arquivos. Se você rodar nx test web-portal e nada no código do portal ou de suas bibliotecas importadas mudou, o Nx pula a execução e entrega o resultado armazenado em cache instantaneamente, acelerando o tempo de build em ambiente local e de CI/CD.
