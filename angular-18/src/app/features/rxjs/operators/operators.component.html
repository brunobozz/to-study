Teoria: Operadores Fundamentais

Operadores são funções que permitem a transformação, filtragem e combinação declarativa de streams de dados.

Operadores de Achatamento (Flattening)

Quando trabalhamos com chamadas HTTP desencadeadas por ações (como digitação ou cliques), lidamos com "Observable de Observables". Os principais operadores de achatamento são:

  • switchMap: Cancela a inscrição interna anterior sempre que um novo valor externo chega. Ideal para rotinas de busca rápidas, impedindo respostas fora de ordem (race conditions).
  • mergeMap (flatMap): Processa todas as emissões concorrentemente. Excelente para uploads paralelos onde a ordem e o cancelamento não importam.
  • concatMap: Enfileira as execuções, rodando um de cada vez em ordem estrita de chegada. Ideal para inserções ordenadas no banco ou ações que exigem processamento sequencial.
